    Inverter SolaX
    Per il risparmio: ogni kWh di sole nella Tesla vale il prezzo che paghi meno quanto ti avrebbero pagato immettendolo (0 se non ti pagano).
    Previsioni del sole
    La resa dell'impianto la ricavo da sola confrontando la produzione con il meteo: dopo qualche giorno di uso le previsioni diventano precise.

    Collega la Tesla da qui

    Sette passi, una volta sola. Serve l'account Tesla dell'auto con la verifica in due passaggi attiva. Puoi interrompere quando vuoi: i passi fatti restano.

    1. Crea la chiave dell'app

      La chiave firma i comandi per l'auto e resta solo in questo telefono.

      Chiave creata. Non va mai rigenerata: l'auto sarà legata a questa.

      Crea una chiave nuova

      Solo se hai perso quella vecchia: dovrai ripubblicarla e riabbinarla all'auto.

    2. Pubblica la chiave su GitHub

      Tesla vuole la chiave pubblica su un sito tuo: usiamo GitHub Pages, gratis. Se non hai un account, crealo qui.

      2. Nel repository: Add file → Create new file. Nome .nojekyll, contenuto vuoto, poi "Commit changes".

      3. Di nuovo Add file → Create new file. Come nome incolla questo (le barre creano le cartelle):

      .well-known/appspecific/com.tesla.3p.public-key.pem
